核心数据流
==========

User 
  ↓
orchestrator (指挥家 Agent)
  │
  ├─→ workspace_config    (管理模板和记忆)
  ├─→ agent_guide_generator (生成协作指南)
  └─→ route_message       (与 Agent 对话)
  │
  ↓ [CLI: start pipeline]
  │
PipelineRunner (确定性代码)
  │
  ├─→ StateManager        (持久化状态)
  ├─→ PromptBuilder       (组装 Prompt)
  ├─→ SkillRunner         (调用 Agent)
  │
  └─→ [Checkpoint] →→→ 等待用户确认 →→→ 继续

每个 Agent 可用工具:
  ├─ pipeline_read          (读 Slot)
  ├─ pipeline_write_slot    (写 Slot)
  ├─ pipeline_add_remark    (添加评论)
  ├─ style_get_profile      (获取记忆)
  ├─ style_record_feedback  (更新记忆)
  └─ + 原有的所有工具
