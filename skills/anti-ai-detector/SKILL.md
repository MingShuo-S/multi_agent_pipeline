# anti-ai-detector

> 基于维基百科 AI 写作特征综合指南和 humanizer-zh 方法论，适用于中文内容创作场景。

---

## 适用时机

| 角色 | 时机 | 说明 |
|------|------|------|
| content-writer | Step 4 自我检查 | 写完后逐项自检 |
| quality-reviewer | 审核阶段 | 在"写得好不好"维度额外检查 AI 痕迹 |
| 两者 | 用户反馈说"写得太 AI 了" | 立即执行针对性修复 |

---

## 检测清单

### 1. 填充短语与开场白

| 要检测的模式 | 示例 | 修复方向 |
|------------|------|---------|
| 元评论式开场 | "值得注意的是"、"不可忽视的是"、"需要强调的是" | 直接删掉，让事实自己说话 |
| 引导式表达 | "让我们深入探讨"、"我们来分析一下"、"接下来我们看看" | 删掉，直接进入正文 |
| 自我宣告 | "在当今这个...的时代"、"随着...的发展" | 删掉，直入主题 |
| 冗余转场 | "与此同时"、"除此之外"、"换言之" | 能用句号就不转场 |
| 总结预警 | "综上所述"、"总而言之"、"总的来说" | 结尾直接给结论，不要预告 |

### 2. 公式化结构

| 要检测的模式 | 示例 | 修复方向 |
|------------|------|---------|
| 三段式法则 | "首先...其次...最后" | 打破顺序，用内容逻辑自然衔接 |
| 对比模板 | "A 固然好，但 B 也有其优势" | 直接表达观点，不用平衡句式 |
| 排比结论 | "不仅...更...还..." | 用一句话说清楚 |
| 反问开场 | "你有没有想过..." | 直接陈述事实 |
| 夸张分割 | "一...二...三..." 的分点 | 每段有实质内容，不为分点而分点 |

### 3. AI 高频词汇

| 词汇 | 替换方向 |
|------|---------|
| "深入"（深入探讨、深入理解、深入分析） | 具体描述"怎么探讨" |
| "赋能"、"助力"、"驱动" | "帮助"、"支持"、"推动" |
| "维度"、"层面"、"视角" | "方面"、"角度" |
| "本质上"、"从某种意义来说" | 直接说，不用铺垫 |
| "毋庸置疑"、"显而易见" | 删掉，事实不需要修饰 |
| "一系列"、"各种"、"不同的" | 给出具体数量或名称 |
| "某种"、"某种程度" | 用精确描述替换 |
| "在...背景下" | 直接说背景 |

### 4. 否定式排比

| 要检测的模式 | 修复方向 |
|------------|---------|
| "不是...而是..." | 直接说"是..." |
| "并非...而是..." | 直接说正面观点 |
| "不应...而应..." | 直接说应该怎么做 |
| "不仅是...更是..." | 只说重点 |
| "与其...不如..." | 直接推荐"不如"后面的方案 |

### 5. 句子节奏问题

| 问题 | 表现 | 修复方向 |
|------|------|---------|
| 所有句子等长 | 读起来像机器朗诵 | 混合短句（< 15 字）+ 中句（15-30 字）+ 偶尔长句 |
| 所有段落等长 | 每段都是 3 行 | 有的段落 1 行，有的 5 行 |
| 缺少极短句 | 没有任何 5 字以下的句子 | 加几个短句打破节奏 |
| 缺少断句 | 全是逗号连接的长复合句 | 该用句号就用句号 |

### 6. 缺乏灵魂的症状

| 症状 | 说明 | 修复方向 |
|------|------|---------|
| 没有观点 | 中立报道式写作 | 加入态度（"我觉得"、"这很好/很糟"） |
| 不承认不确定性 | 所有话都说得太满 | 加入"可能"、"我觉得"、"我不确定" |
| 没有个人感 | 从不使用第一人称 | 适当用"我"、"我们" |
| 没有锋芒 | 所有观点都太温和 | 可以表达强烈偏好 |
| 没有幽默 | 全程严肃 | 适当加入轻松表达 |

## 评分标准

完成检查后，给文案打分：

| 分数 | 含义 | 行动 |
|------|------|------|
| A（0-2 处问题） | 自然，可通过 | 不修改 |
| B（3-5 处） | 轻微 AI 感 | 选择性修复高优先级项 |
| C（6-10 处） | 明显的 AI 感 | 必须修复，逐项改写 |
| D（10+ 处） | 典型 AI 生成 | 建议重写 |

---

## 修复流程

检测到问题后，按以下顺序修复：

```
1. 删填充短语（最快，0 损失）
2. 打破公式结构（调整段落/句子顺序）
3. 替换 AI 词汇（用具体描述代替空洞词汇）
4. 调整句子节奏（混合长短句）
5. 注入观点/态度（加入个人色彩）
```

每处修改后问自己："正常人会这么说吗？"
如果不会 → 继续改。
如果会 → 保留，进入下一项。

## content-writer 集成

### 在 Step 4 自检中使用

写完初稿后，逐项检查：

```
[anti-ai-detector] 检查 draft_content:
  1. 填充短语扫描 → 发现 0 处
  2. 公式结构扫描 → 发现 1 处（三段式"首先其次最后"）→ 已修复
  3. AI 词汇扫描 → 发现 2 处（"深入分析"）→ 已替换
  4. 句子节奏分析 → 句子长度均匀，需混合 → 已调整
  5. 灵魂检测 → 有点中立，加了两个"我觉得"
  得分: A（1 处残余，低优先级）
```

### 在迭代修改中使用

用户说"太 AI 了"时，按检测清单逐项扫描修复，改完重新提交给用户确认。

## quality-reviewer 集成

在审核阶段额外检查 AI 痕迹：

```
### AI 痕迹检查
- 填充短语: 0 处 ✓
- 公式结构: 0 处 ✓
- AI 词汇: 1 处（"赋能"）⚠ 建议替换
- 否定式排比: 0 处 ✓
- 节奏问题: 段落长度均匀 ⚠ 建议打断
- 灵魂检测: 轻度缺乏个人色彩 ⚠ 建议加入态度
综合评定: B 级（通过，标注建议）
```

---

## 注意事项

- 修复的目标是**像人写的**，不是追求语言学完美
- 保留原文风格 DNA——anti-ai-detector 不做超出风格范围的改写
- 如果修复后改变了原意 → 保留原文，换其他修正方向
- 分点不是问题，问题是**为了分点而分点**——每个点要有实质内容
- 格式越整齐越像 AI——适当的不整齐反而更真实
