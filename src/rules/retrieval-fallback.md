# 检索补全协议 — 四级 fallback

当 Agent 需要查找知识库信息时：

| 级别 | 动作 | 成功→ | 失败→ |
|------|------|-------|-------|
| L1 | 精确路径读取：`_shared/{userId}/style-dna.json` | 返回 | L1.5 |
| L1.5 | 先读 `.ai.md` 伴侣文件（紧凑版，体积小 40-60%） | 读到概要 | 如需细节读完整版；无伴侣文件直接读完整版 |
| L2 | 读完整 `kb.json` 或 `persona.md` | 返回 | L3 |
| L3 | 返回空，不编造 | — | — |

## 约束

- L3 失败后绝不自行编造信息——宁空勿编
- 所有非直接确认的事实必须标记置信度
